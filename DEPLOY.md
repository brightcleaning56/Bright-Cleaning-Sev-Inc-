# Deploying Bright Cleaning Sev Inc (brightclean.net)

## Requirements
- Node.js 22 LTS, or the provided Dockerfile.
- HTTPS termination in front of the app (managed host or reverse proxy).
- Persistent disk for `data/` (SQLite database) and `uploads/` (bid documents). Both must survive restarts.
- SMTP credentials for `info@brightclean.net` to enable notifications and proposal emails.

## Environment (set on the host, never commit `.env`)
| Variable | Value |
|---|---|
| `NODE_ENV` | `production` (the app refuses to start without a strong `JWT_SECRET`) |
| `JWT_SECRET` | 32+ random characters |
| `ADMIN_EMAIL` | `info@brightclean.net` or the named admin mailbox |
| `ADMIN_PASSWORD_HASH` | Generated by `npm run create-admin` |
| `TRUST_PROXY` | `1` when behind one reverse proxy (needed for per-client rate limiting) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS` | Provider values |
| `FROM_EMAIL` | `info@brightclean.net` |
| `NOTIFY_EMAIL` | Mailbox that receives new bid and inquiry alerts |

## Steps
1. `npm ci --omit=dev`
2. Create the admin account once: `npm run create-admin -- info@brightclean.net "<14+ character password>"` (writes `.env`; copy its values into the host's secret store).
3. Start: `npm start` (or run the Docker image with the `data` and `uploads` volumes mounted).
4. Point `brightclean.net` at the host and force HTTPS.
5. Submit a test bid, inquiry, and career form from the live site, then confirm each appears in `/admin/` and that the emails arrive at `NOTIFY_EMAIL`.
6. Send a test proposal to an internal address and confirm the customer link opens and approve/decline works.

## Backups
- Back up `data/brightclean.db` and `uploads/` daily. Test a restore before go-live.
