# Crew page: test on one real phone

Run this with one crew member before any pilot. The crew page opens full screen from the home screen; there is no native app.

## Before you start
- Use a real phone (iPhone or Android) that a crew member uses on jobs. Note the model and the OS version.
- Use the live site (https://brightclean.net) or the staging copy, and a test customer and job that the owner creates for the test.
- Have the crew member's crew link ready. Do not use a real customer's address.

## Steps
1. Open the crew link in the phone's browser. Confirm the page loads and shows today's jobs.
2. Add the page to the home screen. Open it from the home-screen icon. Confirm it opens full screen with no browser bar.
3. Clock in on a job. Confirm the time entry appears in the admin portal under Schedule.
4. Turn on airplane mode. Clock out and mark one checklist item done. Confirm the page still works and says the change is waiting.
5. Turn airplane mode off. Wait up to a minute. Confirm the waiting change reaches the admin portal and nothing is duplicated.
6. Take one photo for the job. Confirm it attaches to the job in the admin portal.
7. Rotate the phone, lock and unlock it, and close and reopen the app. Confirm the day's jobs are still there.
8. Check text size and tap targets on the phone. Note anything too small to tap or hard to read.

## Record the result
- Phone model and OS: ______
- Each step: pass or fail, with a note on any failure.
- Blocking issues (anything a crew member could not finish a job with): ______
- Decision: pilot ready / not ready, and who decided.

Send the result to the owner. Fix any blocking issue, then run the test again.
