PUBLIC RECORDS COLLECTION AND DATA SOURCE LICENSING POLICY

1. Each source has a compliance record: agency, URL, method, terms URL, commercial reuse decision, redistribution decision, named reviewer, review date and evidence (license, terms snapshot, or written permission).
2. Collection is technically blocked until that record is complete (src/sources/registry.js canCollect).
3. Approved methods: official APIs, official bulk files, records obtained by public records request, licensed feeds. Scraping is disabled platform-wide. No bypassing logins, CAPTCHAs, paywalls or rate limits.
4. Every permit keeps its source link and last-verified timestamp. Missing values stay empty; the system never estimates square footage or valuation and labels reported figures as reported.
5. Sources that stop updating are flagged by the 30-day freshness gate.
