# FDA Q-Submission outline — DentistNow AutoClean Pro 2.0

Status: draft outline for the regulatory specialist. Not submitted. The regulatory specialist should confirm the submission type and format against current FDA guidance before use.

## 1. Device description

- Integrated dental examination-support and automated cleaning station.
- Components: chair with motion, imaging (intraoral scanner and cameras), robotic instrument arm, cleaning instruments (polishing, plaque removal), fluid and suction, sterilization interface, AI analysis software, operator and patient interfaces, independent safety controller.
- Version 1 scope: examination support, validated polishing and plaque removal, each cleaning authorized by a licensed clinician.
- Out of scope in version 1: drilling, extraction, restorative work, subgingival calculus removal, radiography unless ordered by a clinician.

## 2. Intended use (draft for discussion)

An automated system used in a dental clinic under the supervision of a licensed dental professional, to acquire oral images and scans, record medical and symptom information, flag findings for professional review, and perform validated polishing and plaque removal after clinician authorization.

## 3. Questions for FDA

1. Classification. What is the appropriate classification and pathway for the integrated system, given that an ultrasonic scaler is a Class II device under 21 CFR 872.4850? Is 510(k), De Novo or another route expected?
2. Autonomy. How does FDA classify the device at each proposed level of autonomy: (a) clinician-authorized automated cleaning (version 1), (b) clinician-supervised, step-level automation, (c) any future operation without a clinician present? Which evidence does FDA expect at each level?
3. Predicates. Is there a predicate for the robotic cleaning function, the AI analysis function, or the combination? Which would FDA accept?
4. AI software. Which Good Machine Learning Practice expectations apply? What performance data is needed for each finding type (plaque, suspected decay, gum inflammation indicators)?
5. Safety. What is expected for the independent safety controller and for hazards from robotic motion near the oral cavity and airway?
6. Clinical evidence. What clinical study design is acceptable for a supervised cleaning claim? Is a human study needed at the first submission, or only bench and simulated-use data?
7. Cybersecurity. Which pre-market cybersecurity documentation is expected, given current FDA guidance?
8. Infection control. What sterilization and reprocessing validation is expected for the instrument interface?
9. Labelling. Which claims can be made in version 1? Confirm that claims about automated diagnosis or operation without a clinician are not supported.

## 4. Materials to attach

- Device description and intended use (sections 1 and 2)
