DentistNow AutoClean Pro 2.0 — Engineering UI Prototype
======================================================

Open index.html in a modern browser. This is a responsive, clickable front-end prototype with:
- Clinical command center and patient encounter queue
- Patient intake
- Imaging and scan-quality workflow
- AI-assisted clinical review interface
- Procedure authorization gates
- Machine overview
- Robotics and instrument lifecycle
- Independent safety monitor
- Infection-control register
- Reports and device settings

IMPORTANT LIMITATIONS
- All records, metrics and device states are simulated sample data.
- No patient data is collected or transmitted.
- No backend, authentication, EHR connection, imaging hardware, robot controller or safety PLC is connected.
- Buttons demonstrate navigation or prototype feedback only.
- No button can start physical movement or authorize real treatment.
- This is not a medical device, clinical decision tool, CAD package, manufacturing specification or regulatory submission.

Engineering baseline:
- Fully integrated chair, imaging and robotic instrument architecture.
- Professional-supervised cleaning.
- AI observations remain separate from clinician-confirmed findings.
- Independent safety controller; AI/cloud cannot directly command unrestricted motion.
- Validate intended use, risk controls, software lifecycle, electrical safety, infection-control processes, human factors and regulatory pathway before clinical use.
