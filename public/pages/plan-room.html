OPERATING PRINCIPLES

Built for accountable decisions.

The platform should make the status and limits of each workflow clear—not hide them behind a polished interface.

A subscription is not a document license.

Access is based on publisher authorization, package eligibility and user permissions.

Do not share public URLs for restricted files.

Use authenticated, controlled viewing and access revocation.

Acknowledge the current addenda.

Bid submission gates can require confirmation of the latest package revisions.
