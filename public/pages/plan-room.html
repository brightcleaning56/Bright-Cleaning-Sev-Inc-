Plan room · Example
  • Drawings & SheetsSheets indexed by discipline from file names. Open, measure, or run AI analysis on each sheet.
  • SpecificationsProject manuals and specification sections kept with the package they belong to.
  • Addenda & RevisionsNumbered addenda. Bidders are notified and must acknowledge each addendum before they bid.
  • Project DocumentsEvery file for a package in one place. Only the GC and invited bidders can open them.
  • Version ControlEach revision is kept, and you can compare an older revision with the current sheet.
  • Controlled accessDocument links expire after 10 minutes and are checked against the bidder's invitation.
