                Approval rules

                A proposal that meets any of these rules can't be emailed, marked Sent or opened by the customer until the owner approves it. Any later change to its price, scope or terms cancels the approval.

                Database backups

                Running daily

                A backup is made automatically each day and the 14 newest are kept on the server. Download one regularly and store it somewhere safe off the server.

                Integrations (API keys)

                Partner sites, ad landing pages, Zapier or a CRM can send leads straight into Leads. Create a key for each source. A key is shown once: copy it when it appears. Revoke a key any time to stop it.

                NameKey starts withCreatedLast usedStatus
                How to send a lead

                POST to https://brightclean.net/api/integrations/leads with the key in the X-API-Key header and JSON fields: name, email, phone, company, details and source.

                curl -X POST https://brightclean.net/api/integrations/leads \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_KEY" \
  -d '{"name":"Jane Doe","email":"jane@example.com","company":"Example Co","details":"Needs weekly janitorial","source":"partner-site"}'

                Automatic callbacks

                When turned on, the system calls leads marked “Call back requested”. The caller hears that it is an automated assistant, that the call may be recorded, and can press 1 to reach the team.
